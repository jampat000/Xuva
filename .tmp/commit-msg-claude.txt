docs(claude): codify commit-early + git -C safeguards

Two new bullets capturing failure modes from the recent session:

1. Commit edits immediately. The UI cleanup in PR #72 was drafted
   earlier in the session, but the edit was silently reverted before
   reaching a commit and the work disappeared. Lesson: never let an
   Edit/Write sit uncommitted across multiple turns.

2. Always use `git -C <repo-root>` explicitly. PowerShell's CWD can
   reset to a removed worktree path mid-session, which makes
   `git commit` fail with a confusing "outside repository" error
   while `git push` silently succeeds against the previous ref. Also
   prefer `commit -F path/to/msg.txt` over PowerShell heredocs, which
   misfire under the same cwd-reset condition.
