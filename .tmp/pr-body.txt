## Problem
`watchlistStore.svelte.ts` used a lazy `init()` pattern that mutated `$state` variables (`items`, `initialized`) inside `isInWatchlist()`. Because `isInWatchlist()` is called from a `$derived` expression in `movies/[id]/+page.svelte` and `tv/[id]/+page.svelte`, Svelte 5 threw a fatal **`state_unsafe_mutation`** exception — the movie and TV detail pages were completely blank/unrenderable.

## Fix
Initialise `items` eagerly at module load using `$state(loadFromStorage())`. The `init()` function and `initialized` flag are removed entirely. `loadFromStorage()` already handles SSR gracefully.
