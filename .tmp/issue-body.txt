## What

The `/movies/[id]` and `/tv/[id]` detail pages have solid bones (cast carousel, seasons list, metadata correction) but leave several fields from the already-populated `MetadataRecord` unused. This issue tracks surfacing them all.

## Changes

### Type layer
- `MetadataRecord` in `browse.ts` — add typed fields for `logoUrl`, `videoKey`, `trailerPath`, `contentRating`, `directors`, `writers`, `studios`, `productionCompanies`, `networks`, `statusText`, `tagline`, `releaseDate`, `firstAirDate`
- `MovieDetailVersion` in `home.ts` — add `qualityLabel`

### Movie detail page (`/movies/[id]`)
- **Logo treatment** — if `logoUrl` is present use the clearlogo PNG as the page title; fall back to the existing `<h1>` text
- **Content rating badge** — show `contentRating` (R / PG-13 / TV-MA etc.) in the metadata strip
- **Trailer modal** — "Watch Trailer" button; plays `trailerPath` (local MP4) in a `<video>` or a YouTube embed via `videoKey`; dismissed with Escape or backdrop click
- **Quality label chip** — if `versions[0].qualityLabel` is set (e.g. "4K") show a small pill badge next to the play button
- **Director / writer links** — director and writer names become `<a>` links to `/people/[name]`
- **Studio chips** — surface `studios` / `productionCompanies` as small text labels below the action row

### TV detail page (`/tv/[id]`)
- All of the above that applies to series
- **Status text** — "Running" / "Ended" from `statusText` in the metadata strip
- **Network chips** — surface `networks` instead of/alongside studios
