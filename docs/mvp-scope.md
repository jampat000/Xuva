# MVP Scope

## Goal

Build a credible first version of Xuva that proves the playback engine, local-first model, and polished media-library experience.

The MVP is successful when a user can install the server, add a movie or TV folder, open a client, play media, and understand exactly why Xuva chose direct play, remux, or transcode.

## In Scope

- Windows server install path.
- Linux server install path.
- Docker image.
- Web admin UI.
- Local user accounts.
- Device pairing.
- Movies and TV libraries.
- Metadata matching.
- FFmpeg-based probing and transcoding.
- Direct play.
- Remux.
- Audio transcode.
- Video transcode.
- Subtitle handling for common text and image formats.
- Hardware acceleration detection.
- Playback inspector.
- Apple TV client as the first native playback client.
- Android TV client after the Apple TV playback contract is validated.
- iOS and Android mobile companion apps after TV playback is stable.
- User-owned remote access setup guidance.

## Out Of Scope For V1

- Vendor-hosted relay.
- Mandatory cloud accounts.
- Music libraries.
- Photo libraries.
- Live TV.
- DVR.
- Watch parties.
- Social features.
- Plugin marketplace.
- Multi-server federation.
- Commercial streaming aggregation.

## Early Paid Features

- Hardware transcoding.
- HDR tone mapping.
- Offline downloads.
- Advanced subtitle conversion.
- Intro and credits detection.
- Advanced parental controls.
- Server health dashboard.
- Migration tools.
