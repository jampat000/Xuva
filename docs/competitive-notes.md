# Competitive Notes

## Target Competitors

- Plex.
- Emby.
- Jellyfin.

## Common Complaint Themes

Users repeatedly complain about:

- Cloud authentication affecting local use.
- Ads or streaming-service clutter competing with personal libraries.
- Confusing paid feature boundaries.
- Remote access surprises.
- Playback failing without a clear reason.
- Unexpected transcoding.
- Subtitle incompatibility, burn-in, sync, and encoding issues.
- Device-specific client gaps.
- Metadata mismatches.
- Offline download reliability.
- High resource usage during scans and transcodes.

## Vyrden Response

Vyrden should compete by being:

- More private than Plex.
- More polished than Jellyfin.
- Less infrastructure-dependent than Plex.
- More transparent than all three during playback.
- More deliberate about subtitles.
- Clearer about what is free and what is paid.

## Core Differentiator

The user should always know:

- What is playing.
- Whether it is direct-playing.
- Why it is transcoding if it is not direct-playing.
- What they can change to improve playback.
