# Xuva UI Direction

## Product Surface

Xuva is first a movie and TV product. The primary emotional surface is the TV app, not the admin dashboard.

The design should feel like a private cinema library: immersive, fast, premium, and personal. It should not feel like a generic file browser, a streaming-service ad wall, or a homelab control panel.

## Design Pillars

### Cinematic Personal Library

The user's movie and TV artwork should carry the interface. The UI is a quiet stage for posters, backdrops, playback state, and collection context.

### Local-First Trust

The interface should make ownership visible without turning the product into infrastructure software.

Useful trust signals:

- Local server identity.
- LAN or remote route state.
- Direct play/remux/transcode state.
- Offline availability.
- Clear error messages.

Avoid:

- Cloud account-first screens.
- Vendor service dependency language.
- Ads, generic streaming rows, or unrelated content.

### Explainable Playback

Playback diagnostics are part of the product identity. They should be visible when useful and quiet when not needed.

The user should be able to answer:

- Is this direct-playing?
- Is Xuva transcoding?
- Why?
- What can I change?

### Premium, Not Decorative

The visual style should be rich because movie and TV browsing is emotional, but controls must stay predictable for repeated daily use.

Use:

- Large media artwork.
- Focus states designed for 10-foot viewing.
- Sparse but strong typography.
- High-contrast controls.
- Precise status badges.
- Motion that confirms focus and playback state.

Avoid:

- Marketing-page hero patterns.
- Decorative blobs or unrelated abstract backgrounds.
- Overly rounded card-heavy dashboards.
- Tiny low-contrast metadata on TV.

## Visual Mood

Core mood:

- Cinema black.
- Warm light text.
- Deep ink surfaces.
- Aurora teal and signal amber accents.
- One sharp premium accent reserved for focus and primary action.

Xuva should not read as another purple/blue SaaS product. The palette should support media artwork rather than compete with it.

## Product Personality

Xuva should sound:

- Calm.
- Direct.
- Confident.
- Technically precise.
- User-owned.

Example copy:

- "Direct Play"
- "Remuxing container"
- "Burning PGS subtitles"
- "Server unreachable"
- "Remote access is configured by you"
- "Downloaded and ready offline"

Avoid:

- "Something went wrong"
- "Oops"
- "Magic"
- "Cloud required"
- "Recommended for you" rows that are not based on the user's own library.
