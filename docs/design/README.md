# Vyrden Design

The Vyrden design system starts with the movie and TV experience. The TV app should define the emotional quality of the product, then the web admin should inherit the same trust, clarity, and playback transparency in a denser form.

## Prototype

The first runnable UI concept is:

```text
apps/web/prototypes/vyrden-tv-home/index.html
```

It is a static TV-home concept using fictional titles and original poster-style artwork. Use arrow keys across media cards to test the first pass of remote-style focus behavior.
