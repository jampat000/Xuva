# Lorivo Delivery Phases

## Phase 1 — Desktop Owner Web (Current)

Primary goal:
- complete and stabilise Lorivo Server/Web for desktop owner operation

Acceptance target:
- desktop first (`1600x1000` primary, `1920x1080` secondary)

Scope:
- media browsing/playback routes
- setup flow
- owner settings and server control surfaces
- discovery, pairing review, approved device registry

Out of scope for this phase:
- user-account expansion and full auth model redesign
- tablet/mobile UX polish
- native tvOS/Android apps

## Phase 2 — Auth And Users

- owner account lifecycle hardening
- user accounts and permissions
- production access controls and policies

## Phase 3 — Tablet/Mobile Web

- responsive/touch UX polish
- mobile/tablet settings ergonomics
- non-desktop layout refinement

## Phase 4 — Native Clients

- tvOS client
- Android client
- native discovery/pairing/client API consumption
