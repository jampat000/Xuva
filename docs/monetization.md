# Monetization

## Business Constraint

Xuva should avoid recurring infrastructure cost wherever possible. The product should make money from software value, not from carrying user media traffic.

## Free Tier

- Local server.
- LAN playback.
- Basic library scanning.
- Basic metadata.
- Direct play.
- Remux.
- Basic local users.
- Web admin.

## Paid Tier

Candidate names:

- Xuva Pass.
- Xuva Pro.

Candidate features:

- Hardware transcoding.
- HDR tone mapping.
- Offline downloads.
- Advanced subtitle conversion.
- Intro and credits detection.
- Smart collections.
- Advanced parental controls.
- Remote access diagnostics.
- Server health dashboard.
- Migration tools.
- Backup and restore.

## Pricing Direction

Potential pricing:

- Monthly: USD 5.99.
- Yearly: USD 59.
- Lifetime founder pass: USD 149 to USD 199.

The lifetime pass should not include unlimited company-hosted bandwidth or infrastructure. If optional hosted services ever exist, they should be priced separately.

## Positioning

Xuva should be paid because it is polished, dependable, and private. It should not charge users for avoiding artificial pain.
